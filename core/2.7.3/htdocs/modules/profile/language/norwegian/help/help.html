-----Hjelpeinnhold ----------

BESKRIVELSE

Profilmodulen er for å administrere tilpassede brukerprofilfelt.

INSTALLERE/AVINSTALLERE

Ingen spesielle tiltak nødvendig, følg standard installasjonsprosess – pakk ut mappen /profile inn i ../modules-katalogen. Installer modulen via Admin -> Systemmodul -> Moduler.

Detaljerte instruksjoner for installasjon av moduler er tilgjengelig i Brukerhåndbok for XOOPS

DRIFTSINSTRUKSJONER

For å sette opp denne modulen må du:

  • Konfigurer preferansene dine for modulen (se ‘Innstillinger’) og eventuelt profilblokken hvis du har tenkt å bruke den (se ‘Blokker’).
  • Rediger eksisterende kategorier eller legg til nye.
  • Rediger eksisterende felt eller legg til nye. Her kan du angi hvilke felt som skal være synlige i hvilken kategori, og om de skal være synlige under brukerregistrering.
  • Definer rekkefølgen på registreringstrinn.
  • Og til slutt kan du angi tillatelser for individuelle felt - hvilke som er redigerbare, hvilke er søkbare.

Anti-Spam-tiltak

For å minimere søppelpostregistreringer, gjør følgende:

  • gå til Protector-modulen i Admin, gå til Preferences, og deretter nederst, ved dette alternativet: "Stopp forumspam" Sjekker POST-data mot spammere registrert på www.stopforumspam.com-databasen.
    Sett den til "Forby IP (ingen grense)"

  • i /class/captcha/config.php, sørg for at modusen er satt som "tekst":

    returner $config = array(
    'disabled' => usant, // Deaktiver CAPTCHA
    'mode' => 'tekst', // standardmodus, du kan velge 'tekst', 'bilde', 'recaptcha' (krever api-nøkkel)
    'name' => 'xoopscaptcha', // captcha-navn
    'skipmember' => sant, // Hopp over CAPTCHA-sjekk for medlemmer
    'maxattempts' => 10, // Maksimalt antall forsøk for hver økt
    );

  • I profilmodulen, gå til Admin og i det grunnleggende trinnet som ligger på:
    /modules/profile/admin/step.php?id=1
    sett "Lagre etter stopp" til "Nei"


  • I Profilinnstillinger, sett alternativet "Bruk Captcha etter det andre registreringstrinnet" til "Ja" (det er standard)
